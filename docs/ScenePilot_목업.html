사고 직후, 한 번에 한 가지만 안내합니다

당황한 운전자에게 음성으로 해야 할 일을 하나씩 알려 주고, 증거 사진이 충분한지 확인하고, 출처가 붙은 접수용 요약을 만드는 모바일 웹 앱입니다. 과실, 수리비, 법적 책임은 판단하지 않습니다.

이 페이지는 화면 시안입니다. 사진과 AI 응답은 모두 예시이고 실제 모델을 호출하지 않습니다. 구현됨 표시는 동작하는 앱에 있는 화면, 제안 표시는 아직 만들지 않은 화면입니다.

직접 눌러 보기

화면 안의 버튼을 눌러 흐름을 따라가 보세요. 첫 질문에 "네"를 고르면 응급 안내가, 첫 사진은 일부러 흐리게 찍은 설정이라 재촬영 안내가 나옵니다.

단계

    전체 화면

    사용자가 만나는 화면을 순서대로 모았습니다. 사진 속 장면은 일러스트이며 실제 사고 사진이 아닙니다.

    설계 원칙

    AI를 쓰는 곳과 규칙으로 정하는 곳을 나눈 이유입니다.

    결정은 규칙이, 관찰은 AI가

    응급 판정, 단계 이동, 사진 통과 여부는 코드가 정합니다. AI(Nemotron VL)는 사진에서 보이는 것을 구조화해 알려 줄 뿐 단계를 바꾸지 못합니다.

    모르면 위험 쪽으로

    부상이나 화재 질문에 답이 모호하면 "모름"으로 처리하고 응급 안내를 먼저 띄웁니다. 응급 안내를 확인하기 전에는 사진 촬영으로 넘어가지 않습니다.

    사실과 추측을 분리

    요약의 모든 항목에 출처 태그가 붙습니다. AI가 읽은 값은 사용자가 확인하기 전까지 "미확인"이고, 찍지 못한 것은 "확인하지 못한 것"에 남습니다.

    요약의 출처 태그

    사용자 진술사용자가 직접 말하거나 입력한 내용
    사진촬영된 사진이 있는 항목
    AI 관찰, 검증 아님AI가 사진에서 본 것. 참고용이며 틀릴 수 있음
    미확인비어 있거나 아직 사용자가 확인하지 않은 값
    자동 기록시각처럼 시스템이 기록한 값
